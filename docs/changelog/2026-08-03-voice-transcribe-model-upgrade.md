# 語音辨識模型升級 + 提示詞加強

日期：2026-08-03

## 背景

使用者反應語音記帳講「芭樂」會被誤聽成「8」，例如「135芭樂刷卡」變成「1358元」——「芭樂」的發音開頭跟「八」很接近，是語音辨識當下把聲音聽錯成數字，不是後面 AI 解析的問題。討論過「能不能學習」（不行，這兩個模型都沒有開放客製化微調）、「能不能串別的 API」之後，查到不用整合新服務：Vercel AI Gateway 底下同一個 OpenAI 供應商就有更新的語音轉文字模型可以直接切換。

## 處理內容

`src/app/api/voice-transcribe/route.ts`：
- 模型從 `openai/whisper-1` 換成 `openai/gpt-4o-transcribe`——OpenAI 官方文件說這個較新的模型辨識錯誤率比 Whisper 系列低，尤其是口音、背景雜音、語速變化這幾種情境，跟這次反映的問題類型吻合。同一個供應商、同一個 Gateway，純粹換模型字串，沒有新增任何串接或憑證。
- 順便加強提示詞：原本的範例句只有「午餐麥當勞120元刷卡」這種連鎖店＋數字句型，沒有蔬果/傳統市場詞彙可以競爭，容易讓「芭樂」這類詞被辨識模型誤判成數字。加了「水果攤買芭樂50元、傳統市場買菜200元現金」這兩個例句，讓模型對這類詞彙有更高的辨識傾向。

## 已知限制

這是機率性改善，不是保證修好——語音辨識本質上偶爾就是會聽錯，換模型跟加強提示詞都是降低發生機率，不是徹底消除。如果之後還是常常誤判，下一步可以考慮：
1. 語音轉出文字後，先給使用者看一眼再手動觸發 AI 解析（目前是轉出文字後立刻自動解析，使用者要等看到金額算好的草稿才會發現辨識錯誤，那時候數字通常已經被吃掉、不好抓）
2. 串接 Deepgram 這類支援「關鍵字加強」的專門語音辨識服務（可以明確提高特定詞彙如「芭樂」的辨識權重）——這是全新的服務整合，需要另外申請帳號跟金鑰，工程量比這次大，先不做
