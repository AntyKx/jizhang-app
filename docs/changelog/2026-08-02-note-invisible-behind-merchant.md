# 修正：備註改了卻好像沒變

日期：2026-08-02

## 問題

使用者反應在明細裡改了備註，畫面看起來沒有變化。

## 原因

交易列表（行事曆/首頁「今天記了 N 筆」、`/transactions`、帳戶明細頁）的標題顯示邏輯是 `商家 || 備註 || 分類名稱`——只要交易有「商家」（AI 快速記帳、拍照掃收據都會自動帶入商家），標題永遠顯示商家，備註改了也不會反映在標題上。查了資料庫，這個使用者確實有好幾筆交易同時有商家跟備註，正好命中這個狀況。

而且編輯視窗（`EditTransactionDialog`）本來就沒有「商家」欄位可以改，商家一旦被 AI 帶入就完全無法從畫面上修正。

## 修正

1. `EditTransactionDialog` 新增「商家（選填）」欄位，可以直接編輯或清空商家，欄位下方加一行說明「明細列表的標題優先顯示商家，沒有商家時才會顯示備註」，讓使用者理解兩者的顯示優先順序。
2. `TodayTransactionRow`（行事曆/首頁）、`TransactionsList` 的 `RegularRow`（`/transactions`、帳戶明細）：當交易同時有商家跟備註時，備註會顯示在標題下方的次要資訊列，不會再被商家完全蓋掉——這樣改備註之後，即使標題還是顯示商家，備註也一定看得到。

## 驗證

`tsc --noEmit`、`eslint`（改動檔案）、`next build` 全過，已用 `npx vercel --prod` 部署。
