# 金額鍵盤：對話框裡蓋住欄位 + 沒有千分位

日期：2026-08-01

## 問題

「新增帳戶」「新增分帳支出」都是彈出式對話框（Dialog），裡面有好幾個欄位。點金額欄位時，`AmountKeypadField` 的鍵盤面板會從螢幕底部滑上來——這個元件原本是為 `/record` 整頁的記帳流程設計的，那邊金額欄位通常位置夠高，鍵盤蓋住下面也沒差。但在對話框裡，金額欄位常常不是第一個欄位，鍵盤一彈出反而把金額欄位本身（甚至其他欄位）蓋住，使用者看不到自己正在打的數字，容易打錯。

另外，鍵盤上顯示目前輸入的金額時是純數字（例如 `50000`），跟 App 其他地方顯示金額都有千分位逗號（`50,000`）不一致，大數字位數容易看錯。

## 修正（`src/components/record/amount-keypad-field.tsx`）

1. **鍵盤面板內新增一個數字顯示**：在滑出的鍵盤面板最上方（拉桿下面、數字鍵盤上面）重複顯示目前輸入的金額。這樣不管觸發鍵盤的欄位在頁面/對話框的哪個位置、會不會被鍵盤本身蓋住，使用者永遠能在鍵盤上方看到自己正在打的數字。
2. **加上千分位逗號**：新增 `formatAmount()`，只對整數部分加千分位，小數點跟小數位維持原樣（處理「12.」這種還在輸入中、小數點後還沒打數字的中間狀態，不能直接用 `toLocaleString()`，那個處理不了未完成的輸入）。觸發按鈕跟鍵盤面板內的顯示都套用這個格式化。

因為 `AmountKeypadField` 是全 App 共用元件（12 處金額欄位都在用），這次修正一次套用到所有地方，不是只修這兩個對話框。
