# 調整定價：核心解鎖 NT$99、AI 訂閱 NT$30/月

日期：2026-07-30

## 處理內容

- 核心解鎖一次性付費：NT$199 → **NT$99**
- AI 訂閱：NT$49/月 → **NT$30/月**
- Stripe 的 Price 物件不能直接改金額（immutable），做法是建立新 Price、把兩個 Product 的 `default_price` 指過去、舊 Price 設 `active: false` 封存（不能刪除，因為已經被使用過）
- `.env.local` 跟 Vercel 三個環境（production/preview/development）的 `STRIPE_PRICE_CORE_UNLOCK`、`STRIPE_PRICE_AI_SUBSCRIPTION` 都更新成新的 Price ID
- `/upgrade` 頁面上顯示的金額文字（`NT$199`、`NT$49/月`）是寫死的字串，不是從 Stripe 動態讀出來，這次一併手動改成 `NT$99`、`NT$30/月`

## 驗證

`tsc --noEmit`、`eslint .`、`next build` 全過。已用 `npx vercel --prod` 部署（部署時會重新讀取剛更新的 Production 環境變數）。目前仍是 Stripe 測試模式，這次操作都在測試模式帳號下進行，不影響真實金流。
